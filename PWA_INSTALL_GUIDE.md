# UMAR XM™ Trading Journal V2 — Installable Android Web App

This is the PWA version of the UMAR XM™ Trading Journal V2.

## Install on Android
1. Host this folder on a secure HTTPS website (or a static host).
2. Open the site in Chrome on your Android phone.
3. Open Chrome's ⋮ menu.
4. Tap **Install app** or **Add to Home screen**.
5. Launch **UMAR XM™** from your home screen.

## Important
A PWA requires HTTPS when served online (localhost is an exception). The journal's localStorage data stays in the browser/device. Use the journal's backup/export feature regularly.

- Standalone app display
